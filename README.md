# Minimalist-Homepage-BE

本扩展致力于保护用户隐私。所有配置数据均仅存储在您的本地浏览器中。本扩展不收集、不分析、不向任何第三方服务器发送您的任何个人信息或浏览记录。

点击进入官方文档→ [进入](https://mhdocs.wicm.top/ "官方文档")

查看扩展 [进入](https://github.com/itnproject/Minimalist-Homepage-BE/blob/main/expand.MD "查看扩展")

## 功能特点

双 UI 模式 — 经典UI 卡片式布局，现代UI 沉浸式全屏设计

多引擎搜索 — 内置必应、百度、Google、DuckDuckGo、GitHub，支持自定义引擎

快捷导航 — 自定义添加常用网站链接

深色模式 — 浅色/深色主题一键切换

自定义背景 — 支持图片 URL 或纯色背景

名言名句 — 现代UI 底部随机展示名言（可隐藏）

年月日周 — 显示完整日期信息（可隐藏）

引擎快切 — 搜索框下方快速切换搜索引擎（可隐藏）

快捷栏自隐藏 — 现代UI 快捷栏不操作时自动隐藏

右键菜单 — 覆盖原生右键，支持刷新/剪切/复制/粘贴

扩展系统 — 支持安装第三方扩展（主题/插件），统一 UI 组件

## 使用方法
直接在输入框中输入搜索内容，按回车或点击"搜索"按钮

点击搜索选项切换搜索引擎（默认使用必应搜索）
